# Raport w Looker Studio

[Otwórz E-commerce Conversion · November 2020](https://datastudio.google.com/reporting/cbaa9ff4-41ed-47cd-8f8d-b98d650fef40/page/OB2DG)

Raport przedstawia liczbę oglądających produkty i kupujących, wskaźnik view-to-purchase, aktywność według zdarzeń, dzienną liczbę kupujących oraz konwersję według urządzenia.

## Podgląd raportu

Podgląd wygenerowano z eksportu PDF rzeczywistego raportu. Przed eksportem wyczyszczono zaznaczenia na wykresach.
